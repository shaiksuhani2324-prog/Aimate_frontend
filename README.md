# AI Mate — Frontend 🎓

> **Handwritten Notes to Personalized Learning**

AI Mate is a responsive web application designed for students to transform handwritten notes and lecture materials into structured AI summaries, active recall practice quizzes, and spaced repetition revision schedules.

## ✨ Features
- 📊 **Student Dashboard**: Real-time study statistics, upcoming exam countdowns, and revision trackers.
- 📤 **Handwritten Notes Upload**: Drag-and-drop support for multi-page PDFs, mobile photos, and scanned problem sets.
- ✨ **AI Concept Summaries**: Executive summaries, bulleted key takeaways, and formatted formula cheat sheets.
- 🎯 **Practice Quizzes**: Active recall multiple-choice questions with real-time answer verification and score tracking.
- 🎙️ **Viva Questions**: Flashcards with oral defense prompts and collapsible model examiner answers.
- 📅 **Spaced Repetition Planner**: Weekly timetable scheduled according to the Ebbinghaus forgetting curve.
- 📱 **Fully Responsive**: Optimized for desktop monitors, laptops, tablets, and smartphones.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Tailored Soft Lavender & Academic Blue Theme)
- **Typography**: Plus Jakarta Sans & JetBrains Mono

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
